# Architektur-Dokumentation

Der Einstieg für Fachbereich und Entwicklung ist die
[visuelle Architektur und Business-Logik](architecture-business-logic.de.md).
Sie erklärt Systemgrenzen, Finanzprozesse, Freigaben, Datenherkunft und den
Unterschied zwischen lokalem Betrieb, Mock/UAT und Produktionsreife.

Die `epic-*-completion.md`-Dateien dokumentieren historische Implementierungsetappen.
Aktuelle Aufgaben und Lieferstatus stehen im
[GitHub Project #2](https://github.com/users/Timeless90/projects/2).
